# Visual assets

Town Hall 1–18 icons are Supercell game assets served by WarReport at `https://assets.colinschmale.dev/warreport/townhalls/th{level}.webp`. The URL pattern was identified in the user-provided `warreport.app.har`; the files were retrieved on 2026-10-20 and bundled to avoid runtime dependence on that CDN.

Clan badges use `badgeUrls` returned by the clan/war API and are loaded from `https://api-assets.clashofclans.com/badges/`. They are public image URLs, not credentials.

Supercell game artwork belongs to its respective owners. This community tool is not affiliated with Supercell or WarReport. Application controls use a consistent SVG line icon set; the application crest is an original UI illustration.
